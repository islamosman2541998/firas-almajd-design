# فراس المجد — واجهة الموقع

موقع من 11 صفحة HTML مستقلة، باستخدام CSS وBootstrap 5.3.3 وJavaScript. جميع الصفحات بالعربية والإنجليزية مع RTL/LTR وحفظ اللغة أثناء التنقل. اللوجو هو النسخة الإنجليزية الرأسية الأصلية: الأيقونة فوق والاسم تحت.

## التشغيل

افتح `index.html` مباشرة، أو استخدم Laragon من مجلد المشروع. يمكن أيضًا تشغيل `python -m http.server 4173` ثم زيارة `http://localhost:4173`.

المكتبات والخطوط والصور محلية؛ لا يتطلب عرض الموقع CDN أو عملية build. التواصل عبر واتساب والبريد والهاتف يحتاج التطبيقات أو الاتصال المناسب.

## الملفات

- `index.html`: الرئيسية المبسطة؛ 4 أقسام أساسية: الواجهة، نبذة مختصرة، الخدمات، والتواصل.
- `about.html`, `services.html`, `approach.html`, `contact.html`: الصفحات الأساسية المنفصلة.
- `construction.html`, `fitout.html`, `logistics.html`, `supply.html`, `landscape.html`, `maintenance.html`: صفحات تفاصيل الخدمات.
- `styles.css`, `pages.css`: الهوية والتجاوب والحركة وتخطيطات الأقسام والصفحات، مع دعم تقليل الحركة.
- `app.js`: الترجمة والخدمات والقائمة وتجهيز رسالة واتساب.
- `assets/`: الشعار المستخرج من ملف الهوية، الصور المولدة، الخطوط وBootstrap.
- `qa/results.json`: نتائج اختبارات المتصفح.
- `qa/index-ar-1440.png`, `qa/index-ar-390.png` ولقطات الصفحات بالإنجليزية: مراجعة التصميم النهائي. اللقطات القديمة التي تبدأ بـ`ar-` أو `en-` تخص النسخة الأولى.
- `tools/verify-multipage.cjs`: اختبارات الصفحات والتفاعل باستخدام Playwright؛ مسار الاعتماد ومتصفح Chrome خاصان بهذه البيئة.

## تعديل المحتوى

يمكن تعديل ملفات HTML مباشرة؛ لا تحتاج إلى build لفتح الموقع. ولتعديل العناصر المشتركة وإعادة إخراج جميع الصفحات، استخدم `tools/build_pages.py`. يقرأ الأقسام الأساسية من `tools/templates/home-base.html` وبيانات الخدمات من `tools/services.json`. الترجمة الجديدة مكتوبة بجانب النص في `data-ar` و`data-en`، والترجمات الأساسية في `app.js`. مكتبة بناء HTML موجودة محليًا في `tools/python_libs` ولا تدخل في تشغيل الموقع داخل المتصفح.

عند تغيير بيانات الخدمات، حدّث كذلك مصفوفة `services` في `app.js` لتبقى قائمة النموذج وأقسام الخدمات متطابقة. استخدم خادمًا محليًا لضمان مشاركة تفضيل اللغة بين الصفحات؛ سلوك localStorage عند فتح ملفات `file://` يعتمد على المتصفح.

المحتوى مبني على الملفات والصور المقدمة. استُخدم رقم الهاتف `+966503371820` والبريد `FIRAS-CH@FIRASALMAJD.COM` الواردان في بطاقة الأعمال. تحتوي ورقة المراسلات على بريد بديل. بيانات التواصل المشتركة موجودة في القالب وباني الصفحات و`app.js`، ويجب إبقاؤها متطابقة عند تعديلها.

صور العمارة تصورات تعبيرية مولدة، وليست أعمالًا منفذة أو سجل مشروعات للشركة. لم تضف الواجهة أرقام إنجازات أو شهادات أو عملاء غير موثقين.

النموذج لا يخزن بيانات ولا يرسلها إلى خادم خاص بالموقع. يتحقق من الحقول ويجهز رابط واتساب؛ المستخدم يراجع الرسالة ويرسلها بنفسه. يوجد رابط بديل إذا حجب المتصفح النافذة الجديدة. اختيار «ناقش هذه الخدمة معنا» من صفحة خدمة ينقل الاختيار إلى نموذج التواصل. لا توجد خدمة إرسال بريد أو backend.

## التحقق

تم اختبار الصفحات الـ11 بالعربية والإنجليزية بعروض 320 و375 و390 و768 و1024 و1440 و1920 بكسل في Chrome: 154 حالة صفحة/لغة/مقاس، دون تمرير أفقي أو صور مفقودة. شملت المراجعة الروابط الداخلية، التنقل بين الصفحات، القائمة وإغلاقها بزر Escape، أقسام الخدمات والأسئلة الشائعة، حفظ اللغة، اختيار الخدمة من صفحة التفاصيل، الحقول المطلوبة، بقاء بيانات النموذج عند تغيير اللغة، رابط واتساب دون إرسال أي رسالة، وحركة ظهور المحتوى. لا يعني ذلك اختبار كل جهاز فعلي أو كل متصفح.

## الصور

تم استخدام أداة ImageGen المدمجة لتوليد 7 صور: صورتا العمارة والفناء، و5 صور إضافية للإنشاءات والمقاهي والنقل والمواد والصيانة. أوصاف التوليد في `assets/image-prompts.md` و`assets/service-image-prompts.md`، والصور النهائية في `assets/*.webp`.
